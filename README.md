# Mixtape by Melvin

A first, browser-only prototype for a small, invite-only music listening website.

## Preview locally
Open `index.html` in a modern browser. No build step or dependencies are required.

## What this prototype demonstrates
- Editorial music-library homepage and responsive layout
- Song browsing, album grouping, and search
- Persistent bottom player controls
- Local, browser-only audio preview using the player button's file picker
- Device-local "loved songs" reactions (saved in localStorage)

## Important prototype limits
- The six displayed tracks and album details are illustrative placeholders, not real catalogue entries.
- No music is included in this repository.
- Selecting an audio file plays it locally in your browser only. It is **not uploaded**, stored, or shared with anyone.
- Likes are stored only in the current browser. There is no server-side reaction count.
- There is no admin login, cloud storage, access control, or protected streaming yet.
- A GitHub Pages deployment of this prototype is a public website. Do not add copyrighted audio or private files to this repository.

## Next milestone
Choose and verify a genuinely zero-cost storage and access-control architecture before connecting uploads or sharing links. A secret URL alone is not access control.
